# L103 + DRV8316C 调参手册（2026-10-23）

对象：CH32L103K8U6 + DRV8316C 一体板，母线 24 V，MY-4621F（22 极 = 11 极对）+ MT6701（14 位）。
本文说的"当前值"= 2026-10-23 烧的 git 版本 `cd8beb9`。**设计值/实测值分开标**，没依据的一律写"未实测"。

---

## 0. 先记住三层结构

| 层 | 存在哪 | 改法 | 掉电后 |
|---|---|---|---|
| 编译期默认值 | `board.h` 的 `#define` | 改代码 -> `make -B` -> 烧写 | 保留（在固件里） |
| 运行值 | RAM（`motor` 结构体 / PI 对象） | 串口命令、CAN 命令、GUI | **丢**，回默认 |
| 持久配置 | Flash 最后一页 `0x0800FC00` | 只有 4 项：节点号 / 极对数 / 电流上限 / 母线电压 | 保留 |

**关键**：速度环增益、位置环 kp、PLL 带宽、电流环增益、速度上限、加速度上限、对齐电压
**都只在 RAM 里**，一复位就回 `board.h` 的默认值。想永久改就得改 `board.h` 再烧。

## 1. 怎么知道现在是什么状态

串口 **COM15 / 115200 / 8N1**，一条命令一行，回车结尾。

`?` 状态帧：

```
ST mode=OFF en=0 al=0 flt=0/0 pos=0.000 vel=0.00 iq=0.000 id=0.000 th=1.812
   ref vel=0.00 iq=0.000 vd=0.00 vq=0.00 idfw=0.000 imax=0.000 vbus=23.9 isr=20us(max 21us) pk=1us(max 25us)
```

| 字段 | 含义 | 判读 |
|---|---|---|
| `mode` | OFF / ALIGN / TORQUE / VELOCITY / POSITION / OPENLOOP | 期望哪个环就看这里 |
| `en` | 驱动使能 | 1 = 桥已合上 |
| `al` | 是否已对齐 | **上电/复位后是 0**，第一次使能会自动对齐 |
| `flt` | 故障标志 / 故障码 | 0=正常 1=过流 2=驱动 nFAULT 3=抖动（仅带保护那版） |
| `pos` | 机械位置 rad（本次上电内） | 掉电不保持 |
| `vel` | 机械角速度 rad/s | **MOT_OFF 分支不刷新，停机后是旧值，别当在转** |
| `iq` / `id` | q/d 轴电流 A | 空载保持时应接近 0 |
| `th` | 电角度 rad（0~2π） | 对齐完成时≈0 |
| `imax` | 本拍三相电流最大值 | 对堵转/跑飞最灵敏 |
| `vbus` | 母线实测 V | 与电源表对得上 |
| `isr` / `pk` | 中断耗时 us | 稳定在 20~25 us 属正常，偶尔 70~90 us 是串口打印 |

`Q` 诊断帧：三相电流与和、占空比、电压圆限幅/饱和计数、编码器帧数/错误/CRC 错/原始角/极对数、
速度峰峰值、20 ms 窗口速度、三组增益、母线、nFAULT。

**看增益最省事的一条**：`Q` 最后一行直接打印 `cur kp/ki | spd kp/ki | poskp`。

### C. CAN（ID = 节点号<<5 | 功能号）

| 功能号 | 用途 | 会不会存 Flash |
|---|---|---|
| 0 | PV 位置+速度（mrad / 0.01 rad/s） | 否 |
| 1 | 纯速度 | 否 |
| 2 | 使能/失能 | 否 |
| 4 | 设机械零点 | **是**（零点存 Flash，见 §3.E） |
| 7 | 速度上限（0.01 rad/s） | 否 |
| 8 | 极对数 / 电流上限 / 母线 | **是** |
| 12 | 节点号（带 0x5A 防呆） | **是** |
| 13 | 对齐（带 0x5A 防呆） | 否 |

**注意**：速度/位置/电流环增益**没有** CAN 入口，只能走串口或改代码。

### D. GUI

GUI 走的就是串口那套字母命令（使能 `E`、失能 `D`、设零点 `F`、回零 `N`、停 `B`，
位置 `P`、速度 `V`）。所以界面上能设的，等价于 B 组命令；界面上没有的增益，
直接在串口终端敲。

### E. 位置与机械零点的掉电保存（`posstore.c`，2026-10-23）

- **存哪儿**：Flash 最后 1 KB 里 `0x0800FD00` / `0x0800FE00` 两页轮换（`0x0800FC00` 仍是参数页）。
  每页 4 条 64 B 记录，写满换页；换页时擦的是**旧的那页**，新记录还在另一页上。
- **写什么**：机械零位 `enc_zero_rad` + 圈数 `enc_rev` + 机械坐标 + "设过零点"标志，带 FNV 校验、回读核对。
- **什么时候写**（只有主循环写，FOC / 中断里从不写 Flash）：
  1. 设零点（`F` / `Z` / CAN 功能 4）：立即排队 —— 但仍要求"不忙、不动"；
  2. 运动停止、**3 s 内净位移 < 0.005 rad（≈0.29°）**：写一次；
  3. **"业务执行过程中"一律不写**：脚本在跑 / PV 没到位 / 恒速还在使能 / 开环在转 / 正在对齐 / `P` 走位没到位。
  位置变化 < 0.01 rad 就不重复写，省擦写次数（一页 4 槽、两页 -> 每 8 次保存擦一次页）。
- **上电恢复**：MT6701 是单圈绝对（14 位 SSI）。用"存下来的机械坐标 + 零点"反推圈数：
  `rev = round((mech_saved + zero)/(2π) - θ_now)`。**断电期间轴转动 < 180°** 才能唯一确定 ——
  本产品 ≤720°，这条成立，所以不需要 ABZ 计数器。断电期间转过超过半圈，位置就会差整圈。
- **观测**：`?` 的最后一行 `pos seq=.. ok=.. fail=.. home=.. busy=.. saved=..`；
  `POS` 单独打印记录内容与待写状态（`pending` / `urgent`）。
- **边界（实测）**：
  - MT6701 手册 INL 典型 ±1.0°、最大 ±1.5° —— "同一个零点"复现到 1° 级是芯片上限；
  - 失能瞬间转子会松（台架实测 0.02~0.04 rad ≈ 1~2°），所以"停下再断电"读到的是松开后的位置；
  - 使能保持时位置环零附近有速度抖动，所以判"停住"用的是**净位移**，不是瞬时速度。
- **2026-10-23 夜 补测（UART，`RESET` 软重启）**：
  - `F` 设零点后 **0.2 s** 就重启 → 重启回来 `home=1`、`pos=0.000`、`seq=4`（urgent 路径不留 3 s 窗口）；
  - 走到 **1.11 圈**（`P6.98`，W0.6，约 12 s）→ 停稳后 `saved=6.980` → 重启回来 `pos=6.980`、`home=1`，
    证明 `rev` 反推在跨圈时也对；
  - 全程 `busy=1` 的时段 `seq` 不变（运动中确实不写）。
- **未测**：真拔 24 V 断电。`RESET` 走的是同一条恢复路径，但冷启动这一条还没在台架上跑过。
- **重烧固件（`make flash`）会把 `0x0800FC00` 参数页和这两页位置记录一起擦掉** —— 位置与零点回到
  "没记录"状态，重烧完要重新设零点、重写参数（`SAVE`）。

## 4. 调参顺序（照这个顺序，别跳）

### 第 1 步：开环（换电机/换板/换固件后的第一步）

```
X           清故障
R3,10       3 V、10 Hz 电频率
?           每 100 ms 看一次 pos / vel / iq
R0,0        停
```

**通过标准**：转向与给定符号一致；`vel` 稳定不跳变；`pos` 单调；没有一顿一顿。
10 Hz 电频率 ÷ 11 极对 = 0.909 圈/s = 5.71 rad/s（算术值）。
2026-10-23 实测 `R5,2` 时 vel 稳定 1.0~1.4 rad/s（理论 1.14 rad/s，算术值）。

**不合格先查**：相序、编码器方向、`PP` 填错、母线。

### 第 2 步：电流零位

`M0`（确保桥没输出）→ `CZ`。回显三个零电压，应在 0.25~3.05 V 线性区内、
三相彼此接近（具体值本次没记录，不作标准）。

### 第 3 步：对齐

`A`，等约 1 s（200 ms 爬升 + 800 ms 保持），回 `al=1`、`th≈0`。

**通过标准**：转子被吸住不晃；`Q` 里三相电流和接近 0。
2026-10-18 实测 3.0 V 时稳态相电流 **0.71 A**。若明显大于这个数，先查相电阻/接线。

### 第 4 步：电流环

先 `RL<实测R>,<实测LmH>` 按模型给一版，再 `C<kp>,<ki>` 微调。
判据：给 `I0.5`（力矩模式 `M2`），看 `Q` 的 iq 能否稳住、三相和接近 0。

### 第 5 步：速度环

```
M3          速度模式
V1.05       10 rpm
V3.14       30 rpm
V10.47      100 rpm
```

**通过标准**（2026-10-18 实测基线，kp=0.05 / ki=4.00 / PLL 150 Hz）：
10 rpm 实测 9.99、30 rpm 实测 29.98、100 rpm 实测 99.94，零位移 0.5%/0%/0%。
2026-10-23 复测：给定 1.05/3.14/10.47 rad/s，实测均值 1.03/3.16/10.77。

**抖/跑飞先停**（`M0`），再降 kp 或 ki，别硬顶。

### 第 6 步：位置环

```
M4
P<目标>     绝对位置，单位 rad
```

**通过标准**：走位不过冲；到位后 `?` 的 `pos` 峰峰 < 0.002 rad。
2026-10-23 实测 kp=20：静止峰峰 0.0010 rad（0.06°）。

### 第 7 步：总线

CAN 1 Mbps，`ID = 节点号<<5 | 功能号`。先用功能号 5（QUERY）确认能应答，再下 PV。

## 5. 坑（都踩过）

1. **改 `PP` 必须重跑 `A`**：对齐零点是用旧极对数算的，不重跑整圈电角度都错（没劲/抖/发热）。
2. **复位后 `al=0`**：第一次 `M3`/`M4` 会先自动对齐约 1 s，这期间界面显示 run 但不动是正常的。
3. **`VS0`/`VS2` 别用**：窗口测速 20 ms 延迟配现在这组增益会跑飞，实测到 -129 rad/s。
4. **停机后 `vel` 是旧值**：`?` 在 MOT_OFF 分支不刷新。
5. **只有 4 项进 Flash**：节点号、极对数、电流上限、母线。`S`/`KP`/`C`/`PB`/`W`/`G`/`VA` 全在 RAM。
6. **改 `board.h` 必须 `make -B`**。
7. **外置 3.3 V 不要和板载 DCDC 同时接**（2026-10-23 出现过一次 Flash 校验不一致）。
8. **串口 115200 不要往上提**：电流环 ISR 约 20~25 us，更高波特率的接收中断会抢不过来，整字节丢。
9. **`M0` 是"停并失能"**（关桥，en=0），`B0` 才是"停并保持"（不断使能）。
