# 接线与上板检查清单（FOC V2 第一次通电）

> 顺序是**故意**排成"只读 → 开环 → 对齐 → 小力矩 → 闭环"的。跳过任何一步，出问题都定位不了。
> 每一步都写了"看到什么才算过"。没看到就别往下走。

## 0. 引脚对照（网表核对 2026-10-08，原理图 2026-10-18 已冻结）

| 功能 | MCU 脚 | 外设 | 备注 |
|---|---|---|---|
| PWM_A | PB0 | U6.27 INHA | TIM3_CH3 |
| PWM_B | PA7 | U6.29 INHB | TIM3_CH2 |
| PWM_C | PA6 | U6.31 INHC | TIM3_CH1 |
| EN_A / EN_B / EN_C | PB5 / PB4 / PB3 | U6.28 / 30 / 32 (INLA/B/C) | 高 = 该相允许导通 |
| nSLEEP | PB15 | U6.23 | 高 = 工作 |
| nFAULT | PA8 | U6.22 | R46 5.1k 上拉，开漏 |
| 相电流 A/B/C | PA1 / PA2 / PA3 | U6.40/39/38 (SOA/B/C) | ADC 注入组 |
| 母线 | PA0 | 分压 49k9/4k7 = 11.617 | 实测过 1.687 V → 19.60 V |
| 编码器 CLK / DO / CS | PB6 / PB8 / PB9 | U5.7 / U5.6 / U5.8 | MT6701 SSI |
| 串口 TX / RX | PA9 / PA10 | — | 460800 8N1 |

**注意本板 A/C 相对旧板对调过**：`PWM_A=PB0=CH3`、`PWM_C=PA6=CH1`。这张表写错 = 采样与 PWM 错相，
现象是"一转就抖/一给力矩就飞"。

## 1. 上电前（万用表，断电状态）

1. `VM` 对 `GND` 通断档：**不能是 0 Ω**（功率级直通）。
2. `3V3` 对 `GND` 通断档：不能是 0 Ω。
3. 电机三相之间：两两约**相等**的低阻（毫欧级），对 GND 不通。
4. 编码器 U5 供电 3V3、GND 到位；`MODE` 脚接 3V3（SSI 模式）。

## 2. 烧写

```
make            # 或 MRS 打开 L103_DRV8316C_FOC_V2.wvproj → F7
make flash      # WCH-LinkE (RV 模式) + OpenOCD
```

`make flash` 成功的样子：`device id = 0xfd29abcd` / `Programming Finished` / `Verified OK`。

> **`WCH-Link failed to connect with riscvchip`** 是通用话术，别照着它去查 BOOT/ISP。顺序：
> ① 量 3V3 轨和 MCU 的 VCC 轨（量到引脚/就近电容）→ ② 通断量 SDI 两线到 PA13/PA14 →
> ③ 补焊（QFN 的散热焊盘 EP 是唯一的地）→ ④ 最后才怀疑 WCH-Link 模式/速率。
> 2026-09-25 那次结案就是**虚焊**。

## 3. 第一步：只读 banner（**电机不要转，可以不给 24V**）

上电/复位后串口应看到（原文格式）：

```
=== CH32L103 + DRV8316C FOC V2 (build ... ) ===
CLK:96000000  PWM:20000Hz  Ts:50.00us
LOOP: cur=20000Hz spd=1000Hz pos=200Hz enc=5000Hz
DRV: nSLEEP=1 nFAULT=0
ENC: raw=8123 crc=OK
CSA: zerov A=1.7xxx B=1.7xxx C=1.7xxx | selftest jeoc=1 ok=1 JDR=.../.../...
CSA: 当前 ia=... ib=... ic=... A (DRV 未使能时应≈0)
VM: 23.9x V (分压比 11.617)
GAIN: cur kp=1.2566 V/A ki=8419.5 V/(A*s) | pp=11
SAFE: 驱动未使能, 桥高阻。输入 'e' 使能, '?' 看状态, 'Q' 看诊断
```

逐行判据：

| 行 | 过 | 不过怎么办 |
|---|---|---|
| `CLK` | 96000000 | 时钟没起来，先别往下走 |
| `DRV nSLEEP=1 nFAULT=0` | 两个都对 | `nSLEEP=0` → PB15 没输出；`nFAULT=1` 一直低 → 查 8316C 供电/焊接 |
| `ENC crc=OK` | OK | `MISMATCH` 或 `raw=0` → 编码器没接/CLK 被 CC1 下拉拖住（代码已清 `CC_PD`）/`ENC_HALF_NOP` 要加到 8 |
| `CSA selftest jeoc=1 ok=1` | 两个都是 1 | `jeoc=0` → ADC 注入链没通（SCAN/JEXTTRIG），后面全是假的 |
| `zerov A/B/C` | **三相彼此接近**且 1.5~1.9 V 区间 | 某一路明显偏 → 该相 CSA 输出/走线有问题。（旧板实测过 1.7995/1.7961/1.7970 V；本板不要求同一个值，要求三相接近且稳定） |
| `ia/ib/ic` | 都≈0（<0.05 A） | 不为 0 → 桥漏电或零点没标，先 `CZ` 再不行查硬件 |
| `VM` | 与实际母线差 1% 内 | 差太多 → 分压比不是 11.617（板上电阻换过？） |

## 4. 第二步：`Q` 看采样链

```
Q
```

- `csync=` **必须在涨**（隔 1 s 再看一次）。不涨 → 采样链没通，别通电。
- `miss=` 不该一直涨（涨 = 谷值取数太晚/中断被挤）。
- `enc err=` 必须是 0（涨 = SSI 时序太快，`ENC_HALF_NOP` 4→8）。

## 5. 第三步：`?` 看中断耗时（**这条决定这版能不能用**）

```
?
```

看 `isr=xx us(max xx us)` 和 `pk=xx us(max xx us)`。一拍只有 **50 µs**。

| 现象 | 结论 |
|---|---|
| 两个 `max` 都在 15 µs 以内 | 余量充足 |
| 谷值 `max` 逼近 40~50 µs | 软浮点吃满了，要么降电流环频率，要么改定点 —— **别急着跑闭环** |
| 峰值 `max` 明显大（>20 µs） | 大概率是读编码器（32 个时钟）占的，可把 `ENC_READ_DIV` 加大或减 `ENC_HALF_NOP` |

## 6. 第四步：开环慢转（验相序 + 编码器方向）

**母线接 24 V，电机轴悬空（不拖负载）**，然后：

```
L1.0          # 电流上限先压到 1 A
M5            # 开环模式
R2,1          # 2 V / 1 Hz 电频率 → 约 5.5 rpm 机械（算术：1/11 转每秒）
Q             # 边转边看
```

过判据：
1. 转子**平滑慢转**，不一顿一顿、不啸叫。
2. `Q` 里 `ia/ib/ic` 三相幅值接近（相差 < 20%），`sum≈0`。
3. `enc raw` 单调变化，**不跳大数**。
4. **记下**：`enc raw` 变大时，转子是哪个方向。

如果三相幅值明显不等或 `sum` 不小 → 相序/采样通道对不上，**停下来查线**，别进闭环。

`R0,0` 停止。`d` 断电。

## 7. 第五步：对齐

```
e             # 通电（未对齐会自动对齐）
A             # 也可以单独再跑一次
?
```

- `al=1`、`pos` 在一次 `A` 之后**基本不动**（±0.01 rad 级）。
- 对齐全过程约 1 s（200 ms 爬升 + 800 ms 保持，`ALIGN_TIME_MS_DEF`）。
- 对齐也受 **4 A 过流跳闸**保护（`flt=1/1` 会立刻撤 EN 回到 OFF）。
  一按 `A` 就跳 → `VA` 对这颗电机太高，`VA1.5` 再试。

## 8. 第六步：小力矩（**贴住当前位置**，不是"给个小数字"）

```
M2            # 力矩模式
I0.3          # 0.3 A
?
```

判据：`iq` 跟上 0.3 A（±10%），转子**有一个明确方向**的力，`pos` 只小幅移动。
若 `iq` 与给定符号相反或轴往反方向顶 → **`ENC_DIR` 或相序反了**，先 `d` 断电再改。

`I0` 归零、`d` 断电。

## 9. 第七步：速度闭环

```
e
M3
W20
V2            # 2 rad/s ≈ 19 rpm
?
```

- `vel` 跟上 `ref`，`iq` 平稳（不该大幅来回）。
- 若来回摆（极限环）→ 先降速度环增益 `S0.1,10`，再查 `isr` 耗时。

**低速抖不抖，要按轴位扫，不能单点判**（旧工程 2026-10-14 踩过）：
同一组参数下 -0.06 / -0.14 rad 抖、-0.181 rad 不抖。判据用 `?` 里的 `vq` 峰峰值
（旧工程用 `q_pp > 1 V` 判抖），至少扫 6 个轴位。

## 10. 出问题怎么查（按现象）

| 现象 | 先查 |
|---|---|
| `e` 之后电机完全不动、`iq` 有值 | EN 有没有真的抬起来（`DRV8316C_IsEnabled`）/ nSLEEP / 8316C 供电 |
| `e` 之后立刻过流跳闸（`flt=1/1`） | 电流极性 `CS_SIGN_*`、相序、`ENC_DIR`；先用 `CS0,-1` 之类试 |
| `A` 一对齐就跳闸（`flt=1/1`） | 对齐电压过高（`VA` 降下来）；否则查相间短路/电机堵住 |
| `R<v>,<hz>` 一给就跳闸（`flt=1/1`） | 相序接错或电压给大了；先 `R1,0.5` 极小量试 |
| 一转就抖，静止不抖 | 编码器方向错（正反馈）；角度外推（`enc_err`、`miss`） |
| `iq` 跟不上给定、`vq` 顶到 `vlim` | 电流环增益太小 / R 估大 / 母线太低 |
| 低速来回摆 | 速度环增益、`OMEGA_LP_ALPHA`、位置环 P |
| `csync` 不涨 | ADC 注入链（SCAN、JEXTTRIG）、`miss` |

## 11. 已知没验证的（第一次上板必须确认）

1. `ENC_DIR = +1`（编码器计数方向）
2. `CS_SIGN_A/B/C = +1`（三相电流极性）
3. `CUR_L_H_DEF = 1 mH`（电感，电流环增益按它算的）
4. `ENC_HALF_NOP = 4`（SSI 半周期，没上示波器）
5. 20 kHz + 软浮点的中断耗时（靠 `?` 的 `isr`/`pk`）
