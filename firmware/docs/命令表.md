# FOC V2 命令表（UART1，PA9=TX / PA10=RX，默认 115200 8N1，见 board.h 的 DEBUG_BAUD_DEFAULT）

> 这是**新的一套**，和旧固件（`CH32L103_DRV8316C_FOC_CAN`）的命令**不兼容**，旧的 `G/P/V/#/E/..`
> 一个都不保留。旧上位机脚本要按这张表重写。
>
> 大小写敏感。数字可以带小数和负号（轻量解析，`Cmd_ParseFloat`，不拉 `atof`）。
> 每条命令以 `\r` 或 `\n` 结尾。

## 0. 安全底线

- 上电后**桥是高阻**（EN 全低），必须 `e` 才通电。
- `e` 时如果还没对齐过，会**自动先跑一次对齐**（约 1 s），然后进请求的模式。
- 有故障（`fault!=0`）时 `e` 不放桥，先 `X` 清故障。
- `d` 是**真断电**（撤 EN → 输出高阻），不是"占空比写 50%"。
- **4 A 过流跳闸对闭环、对齐（`A`）、V/f 开环（`R`）三条路都生效**（`MOTOR_OC_TRIP_A`，设计值）。
  对齐一合闸就 `flt=1/1`，说明对齐电压对这颗电机太高：先 `VA1.5` 再 `A`。

## 1. 看状态

| 命令 | 作用 |
|---|---|
| `?` | 打两行状态（下面 §1.1） |
| `Q` | 打诊断（下面 §1.2） |
| `MG` | 读 MT6701 的 `Mg[3:0]` 磁场状态（`NORMAL/STRONG/WEAK`、按压、超速） |
| `ST1` / `ST0` | 开 / 关 100 ms 自动打一次 `?` |

### 1.1 `?` 输出

```
ST mode=VELOCITY en=1 al=1 flt=0/0 pos=1.234 vel=2.10 iq=0.312 id=0.004 th=0.512
   ref vel=2.10 iq=0.312 vd=0.02 vq=1.35 vbus=23.9 isr=8us(max 21us) pk=12us(max 19us)
```

| 字段 | 含义 | 单位 |
|---|---|---|
| `mode` | `OFF/ALIGN/TORQUE/VELOCITY/POSITION/OPENLOOP` | — |
| `en` / `al` | 桥已通电 / 已对齐 | 0/1 |
| `flt=a/b` | `a`=有无故障，`b`=故障码（1=相电流过流，2=8316C nFAULT） | — |
| `pos` / `vel` | 机械位置 / 机械角速度 | rad, rad/s |
| `iq` / `id` | d/q 实测电流 | A |
| `th` | 本拍用的电角度 | rad (0..2π) |
| `ref` | 速度环给定 `vel_ref` / 电流环给定 `iq_ref` | rad/s, A |
| `vd` / `vq` | 电流环输出 | V |
| `vbus` | 母线（分压实测） | V |
| `isr` | **谷值中断**（电流环）本次 / 历史最长耗时 | µs |
| `pk` | **峰值中断**（起采样 + 读编码器）本次 / 历史最长 | µs |

> `isr`/`pk` 的 `max` 是判断"20 kHz 还容不容得下"的唯一依据（50 µs 一拍）。

### 1.2 `Q` 输出

```
DIAG csync=123456 miss=0 valid=1 recon=0
     ia=0.312 ib=-0.150 ic=-0.162 (A)  sum=-0.000
     duty=0.612/0.498/0.410 vlim=13.16
     enc frames=54321 err=0 raw=8123 pp=11
     enc mg=0x0 field=NORMAL push=0 overspeed=0 valid=1
     cur kp=1.2566 ki=8419.5 | spd kp=0.33333 ki=62.83 | poskp=20.00
     vm=23.92 nFAULT=0
```

| 字段 | 用法 |
|---|---|
| `csync` | 成功取到电流帧的次数（**应该在涨**；不涨 = 采样链没通） |
| `miss` | 谷值到了但 JEOC 没置位的次数 |
| `valid` | 当前采样链是否有效 |
| `recon` | 因占空比 > 0.79 而"补一相"的次数（高速时正常会出现） |
| `ia/ib/ic`、`sum` | 三相电流与和（**DRV 未使能时应≈0；三相和应≈0**） |
| `duty` / `vlim` | 当前占空比 / 电压圆半径 |
| `enc frames/err/raw` | 编码器帧数 / 坏帧数 / 14 位原始角 |
| `pp` | 极对数 |
| `enc mg / field` | MT6701 的 `Mg[3:0]` 状态位；`field` 取 `Mg[1:0]`（0 正常 / 1 过强 / 2 太弱） |

## 2. 使能与模式

| 命令 | 作用 |
|---|---|
| `e` | 请求通电（未对齐会先自动对齐） |
| `d` | 断电（桥高阻） |
| `M<n>` | 切模式：`0`=OFF `1`=ALIGN `2`=TORQUE `3`=VELOCITY `4`=POSITION `5`=OPENLOOP |
| `A` | 单独跑一次对齐（约 1 s），跑完回 OFF 并断电 |
| `X` | 清故障（**不会**自动重新通电，还要 `e`） |
| `Z` | 把当前位置记为 0（只改机械零点，不动电角度零点） |

## 3. 给定

| 命令 | 作用 | 单位 |
|---|---|---|
| `I<a>` | 力矩模式给定 Iq | A |
| `V<a>` | 速度模式给定 | rad/s（机械） |
| `P<a>` | 位置模式给定 | rad（机械） |
| `L<a>` | 电流上限（同时限制力矩给定和速度环输出） | A |
| `W<a>` | 速度上限（速度给定、位置环输出都受它限） | rad/s |
| `G<a>` | 速度给定斜率上限 | rad/s² |

> 速度 `V` 是**机械** rad/s。750 rpm = 78.5 rad/s，**超过默认 `W=60`** —— 跑高速前先 `W80` 之类。

## 4. 整定

| 命令 | 作用 |
|---|---|
| `C<kp>,<ki>` | 直接写电流环增益（V/A, V/(A·s)） |
| `S<kp>,<ki>` | 直接写速度环增益（A/(rad/s), A/(rad/s²)） |
| `KP<a>` | 位置环 P（1/s） |
| `RL<ohm>,<mH>` | 按实测 R/L 重算电流环增益（带宽取 `CUR_BW_HZ_DEF = 200 Hz`） |
| `PP<n>` | 极对数（**会让对齐作废**，改完必须重跑 `A`） |
| `VA<v>` | 对齐电压（V，过高会让对齐本身被判成过流 4 A） |
| `SAVE` | 把当前全部可调参数（节点号/极对数/电流上限/母线/三环增益/R/L/限速/加速度/对齐电压/PLL 带宽/速度源）写进配置页 Flash，回 `OK 参数已存 Flash` |

例：`RL6.7,1.0` → 回 `OK cur kp=1.2566 ki=8419.5`。

上电时先按编译默认值装好全套参数，再读配置页：读到就整套覆盖（banner 里 `cfg=Flash`），
没有记录或 magic 不认就停在默认值（`cfg=default`）。

**注意**：`make flash` 会整片擦掉 0x0800FC00 的配置页 —— 每次烧完固件都要重新 `SAVE` 一次。

## 5. 现场排错用

| 命令 | 作用 |
|---|---|
| `CS<idx>,<+1|−1>` | 改某相电流符号（`idx` 0/1/2 = A/B/C），**只在错了的时候用** |
| `CZ` | 桥断电时重标三相电流零点（电机不转、不出力时做） |
| `R<v>,<hz>` | 开环 V/f 自检：`<v>` 伏特、`<hz>` 电频率（自动压进电压圆，上限 200 Hz；相电流超 4 A 一样跳闸） |
| `SD<0|1>` | MT6701 原始角诊断流：打开后主循环按 500 Hz 输出 `seq,raw`（各为十六进制，raw 是 14 位原始计数），不经过任何速度估计，给上位机自己算速度/判平滑。关掉用 `SD0` |
| `VS<0|1|2>` | 速度环吃哪一路反馈：`0` 自动（低速窗口/高速 PLL）、`1` 只用 PLL（**默认**）、`2` 只用 20 ms 窗口。只做对照用 |
| `PB<hz>` | PLL 带宽，默认 150 Hz（5~800 有效） |

`R` 的典型用法（验相序/编码器方向）：`M5` → `R2,1`，转子应当**平滑慢转**（1 Hz 电频率 =
1/11 机械转/秒 ≈ 5.5 rpm）。同时 `Q` 里看：
- `enc raw` 单调变化（不跳）→ 编码器通了
- `ia/ib/ic` 三相幅值接近、`sum≈0` → 三相采样都通了且相位对
- 记下 `enc raw` 增大时对应转子转向，和相序一起判断 `ENC_DIR` 该是 +1 还是 −1

## 6. 一条完整的起步流程（示例）

```
?                 # 看 banner 之后的初始状态
Q                 # csync 在涨? enc_err=0? ia/ib/ic≈0?
e                 # 通电（没对齐会自动对齐 1 s）
?                 # al=1
M3                # 速度模式
W20               # 速度上限先压到 20 rad/s
V2                # 给 2 rad/s（≈19 rpm）慢转
?                 # 看 iq / vel 是否跟上
V0                # 停
d                 # 断电
```
